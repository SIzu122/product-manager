# 商品管理アプリ

HTML / CSS / JavaScriptで作成した商品管理アプリです。

## 機能

- 商品名と価格の登録
- 入力チェック
- 商品検索
- 個別削除
- 全削除
- 合計金額の表示
- localStorageによる保存
- ページ再読み込み後のデータ復元

## 使用技術

- HTML
- CSS
- JavaScript
- localStorage
